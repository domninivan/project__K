Схемами и миграциями Java владеет Бульдин, Go — Домнин, объектами 1С — Корепанова. Ручкина согласует интеграционные данные; изменения схем выполняют владельцы сервисов. Каждый разработчик проверяет свой компонент, Домнин координирует QA. Для собственного компонента требуется другой ревьюер.

Полные две матрицы: [RACI](docs/07-raci.md). R — исполнитель, A — ответственный за итог, C — консультант, I — информируемый. В строке один A и хотя бы один R.

Telegram используется для оперативных вопросов, Discord — для технической работы, Яндекс Телемост — для встреч по актуальному управленческому регламенту. Карточка v0.2 ещё упоминает Zoom; выбор канала требует синхронизации документов. Решения и поручения фиксируются в GitVerse не позднее следующего рабочего дня. Внутренняя приёмка не заменяет проверку преподавателем.
