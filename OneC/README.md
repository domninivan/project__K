# OneC — база MasterPlan_1C (подсистема «Материалы»)

Локальная база 1С для справочников материалов и простого расчёта стоимости.
Работает самостоятельно: Java, Go и веб-сервер не нужны. Публикация, HTTP-сервисы
и интеграции не выполняются.

## Версия платформы
1С:Предприятие 8.5, учебная версия (8.5.1.1150).
Режим: файловая база, управляемое приложение.
Конфигурация: «Мастер-план» (имя `MasterPlan_1C`).

## Структура
- `OneC/src` — исходники конфигурации (выгрузка из Конфигуратора).
- `OneC/README.md` — это описание.

Файл базы (`1Cv8.1CD`) в репозиторий не входит и добавлен в `.gitignore`.

## Загрузка конфигурации
1. Запустить 1С и создать пустую информационную базу `MasterPlan_1C`
   (без конфигурации), файловый режим, каталог вне репозитория, например `C:\1C\MasterPlan_1C`.
2. Открыть базу в Конфигураторе.
3. Меню «Конфигурация» → «Загрузить конфигурацию из файлов…» → выбрать папку `OneC/src`.
4. Нажать F7 (обновление конфигурации базы данных), согласиться на реструктуризацию.
5. Запустить 1С:Предприятие (F5).

## Состав подсистемы «Материалы»
- Справочник `ЕдиницыИзмерения` (код — строка 10).
- Справочник `Материалы` (код — строка 50, наименование, единица измерения — ссылка,
  цена за единицу — число 15.2, неотрицательное).
- Общий модуль `МатериалыСервер` (процедура `ЗаполнитьТестовыеМатериалы()`,
  функция `РассчитатьСтоимостьМатериала(Материал, Количество)`).
- Обработка `РасчетСтоимостиМатериала`.

## Правила справочников
- Код, наименование и единица измерения обязательны.
- Код материала уникален.
- Цена не может быть отрицательной.
- Нарушение любого правила отклоняет запись с сообщением.

## Заполнение тестовыми данными
1. Раздел «Материалы» → «Материалы» → кнопка «Заполнить тестовые данные».
2. Повторное нажатие безопасно: элементы ищутся по коду, дубли не создаются,
   изменённые цены не перезаписываются.

### Единицы измерения
KG, G, L, ML, M, M2, M3, PCS.

### Материалы

|---|---|
| STEEL_40X | KG |
| BRONZE_BR02 | KG |
| STEEL_20X | KG |
| STEEL_SHEET_3MM | KG |
| LUBRICANT_M01 | L |

Цены условные, для демонстрации.

коды правятся только в списке внутри `ЗаполнитьТестовыеМатериалы()`.

## Проверка расчёта
1. Раздел «Материалы» → «Расчёт стоимости материала».
2. Выбрать материал (например, `STEEL_40X`), убедиться, что показаны единица и цена.
3. Для цены 100 и количества 2.5 нажать «Рассчитать»: результат `250,00`.
4. Количество `0` или отрицательное — ошибка «Количество должно быть больше нуля».
5. Материал не выбран — ошибка «Материал не выбран».

Расчёт даёт стоимость одного материала (`количество × цена за единицу`,
округление до двух знаков). Это не себестоимость изделия или заказа.
Количество вводится в единице выбранного материала.
