# Демонстрационные данные

Этот каталог предназначен для небольших безопасных примеров, с которыми другой человек может воспроизвести запуск, тест или демонстрацию.

**Текущее состояние:** в шаблоне данных нет. Предметную область, состав набора и форматы выбирает команда.

Проекту не нужны входные данные? Укажите «Демонстрационные данные не требуются» и не создавайте фиктивные наборы ради заполнения каталога.

## Что допустимо размещать

Используйте вымышленные записи или данные, публикация которых разрешена. Уберите реальные пароли, токены, личные контакты и закрытую служебную информацию. Замена одного имени не гарантирует безопасную анонимизацию целого набора.

Большие или закрытые исходные наборы сюда не добавляйте. Для разрешённых внешних наборов опишите версию, условия доступа и получение; без сохранения секретов в инструкции. Локальные рабочие данные можно держать в `data/local/`, который исключён из новых добавлений правилами `.gitignore`.
