Правила смены статуса

«В работе» — исполнитель подтвердил остаток; «На ревью» — результат передан на проверку; «Принято» — есть принятый результат и критерии выполнены; «Просрочено» — прошёл согласованный срок; «Эскалировано» — решение передано Бульдину. Отдельная отметка «Требует сверки» означает нехватку актуального подтверждения.

Для закрытия записываются дата, PR/commit, результат проверки и принявший участник. При переносе сохраняются прежний срок, причина и новый срок. Предложенная дата не становится согласованной автоматически. На 16 ноября сроки 17 и 26 ноября ещё не прошли.

Исправление версии 0.4: фраза «#4 и #8 закрыты быстрее расчёта» исключена. Для #4 подтверждалось только ревью, для #8 — историческое закрытие. Деление первоначальной оценки на 8 ч/неделю не доказывает фактическую дату завершения.

Go сохраняет завершённые операции и пересчитывает остаток; новый вариант подтверждает начальник. 1С не является посредником этого процесса.
